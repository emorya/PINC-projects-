# Machine Learning & Data Science Projects

### Emory Adelman

A collection of machine learning, data science, and computational biology projects completed during my undergraduate education at San Francisco State University, including coursework through the Promoting Inclusivity in Computing (PINC) program.

My academic background combines cell and molecular biology, computational biology, and bioengineering. These projects demonstrate my experience working with biological and healthcare-related datasets, exploring machine learning models, and interpreting computational results.

## Featured Project Areas

### 1. Medical Imaging & Machine Learning

**Alzheimer's Disease Classification (ADNI)**

Coursework exploring the classification of medical images using pretrained neural networks and transfer learning.

**Brain Tumor Segmentation (BraTS)**

Exploration of MRI image processing and whole-tumor segmentation using deep learning techniques.

### 2. Data Exploration & Predictive Modeling

Projects covering:

- Data exploration, preprocessing, and visualization
- Hyperparameter exploration in regression models
- Classification methods
- Model evaluation and regularization
- Transfer learning

### 3. Computational Biology

Coursework involving biological sequence processing, including:

- FASTA file processing
- Nucleotide analysis
- Sequence alignment
- Biological data manipulation using Python
